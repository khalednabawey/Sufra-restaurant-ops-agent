# Sufra Ops Agent

Operations assistant for Sufra Café & Bakery, a fictional four-branch chain built on public data.

- Pick a user from the menu at the top: each one is a role (owner, area manager, branch manager, staff).
- Ask in Arabic or English. Every number comes from a tool, and each role sees only its own branches.
- Reorders and price changes need your confirmation, then an approver's decision. Nothing changes before that.
